---
title: Convai Pixel Streaming Embed
description: Find the guides and API reference for embedding a published Convai Pixel Streaming experience in a website with React, JavaScript modules, or a script tag.
---

Convai Pixel Streaming Embed puts a published Avatar Studio experience on your own website. The `@convai/experience-embed` package renders the experience, streamed from Convai, in an iframe on your page, and lets your code control its camera, audio, microphone, and chat. The current release is <code class="expression">space.vars.experience_embed_version</code>.

Start by publishing the experience and choosing how to authorize it, then follow the guide for your stack.
