  Find setup, targeting, roster management, transcript, audio, and API guidance
  for conversations with multiple Convai characters in one Unity room.
last_reviewed: "4.6.0"
---

Multi-character conversations place several Convai characters in one shared room. Use this section to configure the starting roster, choose which character receives player input, change the roster at runtime, and attribute events, transcripts, and audio to the correct character.

{% hint style="warning" %}
**Preview availability:** Multi-character conversations are planned for Convai Unity SDK <code class="expression">space.vars.unity_sdk_preview_version</code>. They are not included in the current Asset Store release, version <code class="expression">space.vars.unity_sdk_version</code>. Use an SDK artifact that explicitly includes this preview surface.
{% endhint %}
