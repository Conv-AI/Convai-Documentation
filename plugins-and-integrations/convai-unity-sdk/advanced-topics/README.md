Extend the Convai SDK for Unity through public interfaces that fit your task. Use authentication providers for tokens, identity providers for the signed-in user, character behaviors for ordered event handling, and modules for runtime lifecycle integration.

These pages assume C# experience. For initial scene setup, start with [Getting started](../getting-started/README.md).
