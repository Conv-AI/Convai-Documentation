The Convai Unity SDK exposes two complementary approaches for C# integration. `ConvaiSessionEventRelay`, `ConvaiCharacterEventRelay`, and `ConvaiTranscriptEventRelay` wire events in the Inspector. For scripted reactions and programmatic control, use the `ConvaiEvents` event hub, `ConvaiTranscripts`, the public room services, and each scene component's C# API. Both approaches observe the same underlying SDK state and can be combined.

The multi-character reference cards describe a staging preview planned for Unity SDK <code class="expression">space.vars.unity_sdk_preview_version</code>; those APIs are not included in the current <code class="expression">space.vars.unity_sdk_version</code> Asset Store release.
